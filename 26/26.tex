\section{Introduction}
\label{sec:intro}
% ============================================================

The aim of this project is to build and compare natural language processing models that assign clinical texts to one of 12 medical specialties to answer the following research question:

\smallskip
\noindent\colorbox{black!8}{\parbox{\dimexpr\columnwidth-2\fboxsep\relax}{\textbf{Does a fine-tuned clinical language model that reads only a fraction of each record outperform a classical classifier that reads all of it?}}}
\smallskip

To answer it, we analyse the given data (Section~\ref{sec:analysis}) and balance the classes through augmentation (Section~\ref{sec:augmentation}); starting from the baseline, we develop progressively better models (Section~\ref{sec:models}), compare them on held-out data (Section~\ref{sec:setup}) and study their errors (Sections~\ref{sec:results} and~\ref{sec:discussion}).

\section{Data}
\label{sec:data}
% ============================================================

\subsection{Data Analysis}
\label{sec:analysis}

\textbf{Dataset.} Each record, adapted from a public Kaggle dataset~\cite{kaggle}, has five fields: \texttt{medical\_specialty} (the label, 12 classes), \texttt{description}, \texttt{sample\_name}, \texttt{transcription} and \texttt{keywords}. In \texttt{train.csv}, seven rows have a description that swallowed the records that follow; we split them back, giving 2{,}669 records. Descriptions are short (19 words on average) and transcriptions long (457 words; Figure~\ref{fig:text_lengths}, Appendix A).

\textbf{Class distribution.} Table~\ref{tab:class_dist} shows a strong imbalance, from Surgery with 893 records to Dermatology with 25 (about 36:1), which biases classifiers towards the frequent classes~\cite{imbalance_survey}.

\textbf{Observation 1 --- the same note appears under several specialties.} 731 of the 1{,}838 distinct transcriptions are listed under more than one label (1{,}530 records, 57\%), always with the same description and sample name. This shows that some fields are common among specialties, which can be misleading.

\textbf{Observation 2 --- the label is written in the keywords.} In all 2{,}219 records that have keywords, the first keyword is the specialty itself. This could be used as a shortcut for model training, taking advantage of how the dataset was built. The other 450 records have none.

\subsection{Data Augmentation}
\label{sec:augmentation}

To counter the imbalance (Section~\ref{sec:analysis}), we enlarged every class below 400 records with rule-based synthetic records. Each new record applies one of 15 variants inspired by \ac{eda}~\cite{wei2019eda}, combining synonym replacement (a clinical term map and WordNet~\cite{miller1995wordnet}), word and sentence deletion, adjacent-word swaps, abbreviation expansion and number rewriting. Keywords after the first are subsampled and shuffled; negations, laterality, numbers and dosages are never altered. This added 2{,}979 records, raising the training file to 5{,}648 and reducing the ratio between the largest and the smallest class from about 36:1 to 2:1.

\section{Models}
\label{sec:models}
% ============================================================

We develop models step by step to beat the teachers' baseline (above 49\% accuracy, no per-class F1 below 25\%) while answering the research question.

\textbf{M1.} The baseline, the reference for every change. It reads only the description, lowercased and stemmed~\cite{nltk}, and counts words with \ac{tfidf} for a \ac{mnb}, with default settings.

\textbf{M2.} Reads every field, transcription and keywords included, since the question asks what a classical model can do with all the text. Words are weighted by \ac{tfidf} and a linear \ac{svm}~\cite{sklearn}, learns one boundary per specialty, with class weights so that the rare ones count more. It has no extra feature and no post-processing.

\textbf{M3.} Goes back to little text, the description only, but swaps word counts for Bio\_ClinicalBERT~\cite{bioclinicalbert}, already pre-trained on clinical notes. A linear layer is added and all weights are fine-tuned with PyTorch~\cite{pytorch} and Transformers~\cite{transformers}, since the encoder was never trained to separate specialties. Training uses the augmented data.

\textbf{M4.} The best model: M3 plus the first keyword, which is the specialty itself (Observation~2) and, unlike the text, separates the copies of a note listed under several specialties (Observation~1). Its specialty is added to M3's standardised scores with a weight that no score gap can outvote, so the keyword decides when it exists and M3 decides when it does not. The weight is fixed in advance and M4 needs no training of its own.

% ============================================================
\section{Experimental Setup}
\label{sec:setup}
% ============================================================

\textbf{Datasets.} M1 was trained on the given \texttt{train.csv}, M2 to M4 on its augmented version (Section~\ref{sec:augmentation}).

\textbf{Splits.} 80\% of the original records are used for training and 20\% (534) are held out, stratified and fixed by seed 42, so runs are comparable; augmentation is applied afterwards, to the training part only. \texttt{results.txt} comes from M4 trained on all the records; the given test file was used for nothing else.

\textbf{Evaluation.} Accuracy, macro-F1 and the lowest per-class F1 on the held-out records, against the 49\% and 25\% set by the teachers.

\section{Results}
\label{sec:results}
% ============================================================

Table~\ref{tab:results} shows the held-out results; the last row applies the keyword rule of M4 to M2, for comparison. M4 is the best model (92.1\% accuracy, 89.6\% macro-F1) and meets both automatic conditions (accuracy above 49\%; lowest class F1 70.0\%, Psychiatry-Psychology). By label (Table~\ref{tab:perlabel}, Appendix A), the F1 of M4 is at least 88.9\% in 9 of the 12 specialties; the weakest are Psychiatry-Psychology (70.0\%), General Medicine (79.5\%) and Neurology (82.7\%). The most frequent error (Figure~\ref{fig:confusion}) is Cardiovascular-Pulmonary predicted as General Medicine (6 records). Augmentation made no clear difference for M2 (87.6\% original, 86.3\% augmented), within the uncertainty of about 3 points of a 534-record test set.

\section{Discussion}
\label{sec:discussion}
% ============================================================

\textbf{Research question.} With little text, the description and the first keyword, M4 outperforms M2 (92.1\% against 86.3\%). However, the same keyword rule applied to M2 gives 89.1\%, so the keyword explains most of the gap, and the remaining 3 points are within the uncertainty of the test set. Without the keyword, M3 reaches only 48.9\%, because the description cannot separate specialties that share notes (Observation~1). The answer is yes on this dataset, but mainly because one short field carries the label (Observation~2), not because the language model reads better.

\textbf{Errors.} All 42 errors of M4 fall on the 94 held-out records without keywords, where M3 decides alone (55.3\% accuracy); 22 of the 42 are notes listed under more than one specialty (Observation~1). Three examples (correct label $\rightarrow$ prediction): (i) ``Patient felt dizzy, had some cold sweats, mild shortness of breath, \ldots lost consciousness for a few seconds'' (Cardiovascular-Pulmonary $\rightarrow$ General Medicine): the decisive cue, \emph{Pulmonary Embolism}, is in the sample name, which M3 never reads. (ii) ``Possible free air under the diaphragm'' (General Medicine $\rightarrow$ Gastroenterology): the same note appears in the training data under Gastroenterology. (iii) ``Falls at home. Anxiety and depression'' (Neurology $\rightarrow$ Psychiatry-Psychology): the description is dominated by psychological symptoms.

\textbf{Limitations.} M4 depends on the first keyword being the specialty, which holds in all 2{,}219 training records that have keywords and in 320 of the 398 test records; without keywords its accuracy falls to 55.3\%.

% ============================================================
\section{Future Work}
% ============================================================

With more time, we would give the language model the sample name and the start of the transcription, so that records without keywords use more text, treat the copies of a note as a multi-label problem, and use cross-validation to reduce test-set uncertainty.
